# 평가 프로토콜

누수 규칙은 [ADR 0002](adr/0002-real-data-usage.md)를 따른다. 요약: 학습·튜닝은 시뮬로만, 실측 시나리오 0은 보정 전용, 실측 테스트 결과를 보고 다시 튜닝하지 않는다.

## 데이터 분할

| 용도 | 데이터 |
|---|---|
| 학습 | 시뮬 전체 중 학습 분할 |
| 검증(하이퍼파라미터·임계값) | 시뮬 내부 검증 분할 |
| 보정·기준선 | 실측 시나리오 0 (테스트 제외) |
| 테스트 | 실측 시나리오 2~9, 12~16 + 손상없음 7 (setup 단위 행 기본, 구간 단위 행 보조) |
| 별도 보고 | 실측 시나리오 10, 11 (미시뮬 손상) |
| 제외 | 실측 시나리오 1 |

setup 단위 테스트 행은 13개 시나리오 × 9 setup = 117개다. 클래스 불균형이 크므로(손상없음은 시나리오 7의 9행뿐) 균형 정확도를 주 지표로 쓴다.

## 과제와 지표

| 과제 | 주 지표 | 보조 |
|---|---|---|
| 손상 유무 | 균형 정확도 | F1, ROC-AUC, 시나리오별 탐지율 |
| 손상 그룹 4개 | 균형 정확도 | 혼동행렬 |
| 손상 그룹 3개 (경미 손상 합침) | 균형 정확도 | 혼동행렬 (같은 4그룹 모델의 예측을 합쳐서 계산) |
| 침하 크기 (확장) | 실측 시나리오 0/7, 2~5의 예측 강성 감소율과 침하량의 스피어만 순위 상관 | 시나리오별 예측값 분포 |
| 미시뮬 손상 | 시나리오 10, 11의 손상 탐지율 | 어떤 그룹으로 예측되는지 |

## 비교 실험 (발표용)

1. **특징**: 절대 진동수 vs Δf/f₀. 정규화가 도메인 차이를 줄이는지 확인한다.
2. **그룹 수**: 4그룹 vs 3그룹. 진동수만으로 구분할 수 있는 한계를 보여준다.
3. **평가 단위**: setup 단위(600초) vs 구간 단위(60초). 해상도의 영향을 본다.
4. **기준선(참고)**: 실측만으로 setup 단위 교차검증한 상한, 시나리오 0 기반 이상탐지(예: σ₀ 기준 거리)의 하한.
   - 상한 실험은 실측 손상 데이터로 학습하므로 "참고용 상한"이라고 명시하고, 메인 결과와 섞지 않는다.

## 발표에 명시할 가정

- 학습 데이터 = 시뮬 + 실측 손상 전 기준값 1세트(시나리오 0).
- 실측 센서 위치를 모르므로 고유진동수만 쓴다.
- 시뮬은 선형 해석이며, FDD 추정 오차 구조는 반영하지 않는다(ADR 0001).
