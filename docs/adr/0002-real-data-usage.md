# 실측 데이터는 시나리오 0만 보정에 쓰고 나머지는 전부 테스트

학습은 시뮬로만 한다.
- 실측 시나리오 0(기준상태1)은 세 가지 용도로만 쓴다: FE 모델 보정, 실측 기준선 f₀(setup별 진동수의 중앙값) 산출, 기준 산포 σ₀ 산출. 테스트에서는 뺀다.
- 나머지 시나리오는 전부 테스트에만 쓴다. 테스트의 손상없음 클래스는 시나리오 7(기준상태2)이 대표한다.

실제 SHM 현장에서도 손상 전 측정값 한 세트는 확보할 수 있으므로 현실적인 가정이다. 반면 손상 데이터로 미세조정하는 것은 "시뮬 학습" 주장을 무너뜨리므로 허용하지 않는다.

## 누수 방지 규칙

1. FE 보정과 시뮬 노이즈 크기 추정에는 시나리오 0만 쓴다. 실측 손상 데이터를 보면서 손상 모델링(손상 함수, 강도 범위)을 맞추지 않는다.
2. 임계값과 하이퍼파라미터는 시뮬 데이터로만 정한다(시뮬 내부 검증 분할). 실측 테스트 결과를 보고 조정하지 않는다.
3. 실측의 침하량(mm)은 평가에만 쓴다. 시뮬 손상 강도와 mm의 대응을 실측으로 맞추지 않는다(ADR 0004).
4. 실측을 나눠야 할 때는 반드시 setup 단위로 나눈다. 같은 setup의 구간끼리는 하나의 연속 신호이기 때문이다.
