# 실측 데이터는 시나리오 0만 보정에 쓰고 나머지는 전부 테스트

학습은 시뮬로만 한다. 실측 시나리오 0(기준상태1)은 FE 모델 보정과 실측 기준선 f₀ 산출에 쓰고, 테스트에서는 뺀다. 나머지 시나리오는 전부 테스트에만 쓴다. 테스트의 손상없음 클래스는 시나리오 7(기준상태2)이 대표한다.

실제 SHM 현장에서도 손상 전 측정값은 확보할 수 있으므로 현실적인 가정이다. 반면 손상 데이터로 미세조정하는 것은 "시뮬 학습" 주장을 무너뜨리므로 허용하지 않는다.

실측을 분할해야 할 때는 반드시 setup 단위로 나눈다. 같은 setup의 구간끼리는 하나의 연속 신호이기 때문이다.
