# 시뮬 손상 강도는 연속값으로 샘플링하고 실측 mm에 맞추지 않음

시뮬레이터의 손상은 그룹과 손상 강도(severity, 0~1 연속값)로만 정의한다. 실측 시나리오 번호나 침하량(20/40/80/95mm)에 대응하는 이산 값을 만들지 않는다.

mm와 FE 강성 감소의 대응을 정하려면 실측 손상 데이터를 봐야 하고, 이는 테스트 누수다(ADR 0002). 연속 샘플링을 하면 분류기가 특정 강도 몇 개만 외우지 않게 되는 장점도 있다.

## Consequences

- 시뮬 행에는 `scenario`가 없고 `group`, `severity`, `stiffness_loss`만 있다.
- 침하 회귀는 시뮬의 `stiffness_loss`를 목표로 학습한다. 실측에서는 예측값이 침하량 순서(20 < 40 < 80 < 95mm)와 단조 관계인지(순위 상관)만 평가한다. mm 단위 오차는 평가하지 않는다.
